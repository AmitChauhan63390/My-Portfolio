# Amit Chauhan — Portfolio

Personal portfolio and project showcase. Built with React, Vite, and Framer Motion.

## Featured work

- **[ApproveDeck](https://approvedeck.com)** — Contracts, approvals, and invoicing in one place (SaaS).
- N-Queen Visualizer — Backtracking algorithm visualization.
- Hangman — Vocabulary game (vanilla JS).

## Run locally

```bash
npm install
npm run dev
```

Build for production:

```bash
npm run build
npm run preview
```

## Stack

- React 18
- Vite
- Sass
- Framer Motion
